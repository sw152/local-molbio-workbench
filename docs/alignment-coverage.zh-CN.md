# 已报告配对位置的覆盖审阅

此功能回答“哪些参考位置有报告过的读段碱基配对、哪些需要继续查看”，帮助从一批比对结果中定位待复核区间。它不是高质量覆盖、共识或质粒通过判定。

## 定义与计算

只读取同一修订下已由 queue.finish 正式发布的比对结果，先复核来源映射，再对每条命中的参考/原始 query 坐标、方向、eqx CIGAR、paired_blocks 和插入/缺失计数做几何一致性检查。任一命中不一致则拒绝整份总览，不静默跳过后继续汇报。

每条读段的候选区间先取并集，再累加记录深度。同一记录的重叠候选或多个配对块在同一位置最多计一次；不同记录仍分别计数，不声称它们来自独立分子。圆形双拷贝等价命中沿用核心去重结果，raw_hits 数量不会增加记录深度。

内部保留四个精确轨道：只有一条已报告命中且没有 withheld 的记录配对深度；其他有可用命中的记录配对深度；对应两类记录的删除深度。withheld 命中自身不产生任何位置证据；一条记录即使另有可用命中，只要存在 withheld，所有可用位置仍进入不确定类别。没有任何命中且没有 withheld 的记录单独计为未报告命中。

参考位置按以下互斥类别分区，总和等于参考长度：

- single_reported_alignment_bases：至少一个“单条已报告命中且无 withheld”记录与该位置配对。**单条已报告命中不表示唯一映射。**
- ambiguous_only_bases：只有多候选或伴随 withheld 的记录配对，无上述单命中记录证据。
- unpaired_bases：没有任何已报告可用命中的读段碱基与该位置配对。

删除位置从参考方向的 CIGAR D 推导，环形时拆分跨起点区间。删除不加入配对深度；插入不消耗参考位置。X 和与 N 配对的位置仍属于配对位置，因此配对不表示精确匹配，更不表示质量合格。删除证据区间可以与其他记录的配对位置重叠；deletion_evidence_bases 是单独的非互斥统计，不能与前三项相加。

重复序列附近的等价缺失可能有不同坐标表示。这里忠实使用实际报告的 CIGAR，不做 indel 归一化、不推断共识删除。合成 6 bp 缺失实例在设计坐标 [240,246) 与实际 minimap2 [239,245) 删除后序列相同；验收同时检查序列等价性和实际报告位置，未强行改写工具输出。

## API 与页面

`GET /api/revisions/{revision_id}/alignments/{job_id}/coverage`

- kind：unpaired（默认）、ambiguous_only、deletion。
- limit：默认 20，范围 1–100；offset 非负。
- 返回 job_id、已发布 attempt_number、参考 SHA-256、summary，以及带 items/total/limit/offset/has_more/kind 的 regions。
- 区间为 0 基半开 [start,end)，包含 length_bp，排序后合并相邻同类别区间。圆形参考的起点/终点仍按线性坐标分别列出，不返回 start>end 的歧义区间。
- summary.schema=localmolbio.alignment-paired-coverage，schema_version=1。scope=reported_paired_positions_quality_unassessed；质量、唯一性、独立分子、整参考验证标记均为 false。此派生算法的语义变化需要升级其版本。
- 未成功发布、未知源 schema、来源映射错误或几何不一致拒绝返回；修订与适配器隔离、错误和凭证边界复用比对 API。

页面在逐读段结果前展示基数构成条和三个互斥类别的精确 bp 数。**该条是数量组成，不是沿参考坐标绘制的空间图。**下方选择待复核区间类别，每页 5 项，显示完整坐标和长度；删除说明明确可能与其他配对记录重叠。筛选和翻页保留对应任务/尝试身份，刷新失败保留上次已加载内容并标记可能过时，切换构建后旧响应不生效。

区间清单中的 Inspect related reads 可打开关联读段；仍未实现空间深度图、共识/变异报告或质量过滤。

## 实现范围与验收

按记录区间取并集后使用差分数组，内部生成精确的深度游程；API 不返回全部游程。每次请求仍解析完整的有界 JSON 并计算总览，最多 200kb 参考、5,000 reads 的现有适配器限制不变，没有大规模增量索引或延迟性能承诺。历史快照读取不会重新验证当前磁盘原文件。

17 项专项测试包含正反向和线性终点、跨起点删除、插入/错配/N、重叠候选去重、圆形等价副本、withheld、无命中、不同记录覆盖删除位置，以及非法几何整份拒绝。20 组固定种子的多记录/多候选场景用独立逐位置集合真值核对精确深度；真实 minimap2 API 用例验证缺失、分页、跨修订/适配器、参数与来源错误。

M2 Chrome 使用真实 minimap2 的合成读段，检查 900bp 全部出现配对证据时仍单列 6bp 删除与未报告/withheld 记录，验证三个筛选、覆盖请求失败恢复，以及桌面/390px 总览与区间截图。没有实际仪器数据或独立分子支持、临床或全质粒验证结论。

## 从区间进入原始记录

点击区间后，默认查看与该区间有配对或删除重叠的所有已报告可用候选。可切换 Paired positions only / Deletion positions only，每页 3 条原始记录，翻页和刷新保留当前区间与关系。Show all reads 清除筛选；Back to overview 返回总览且保留筛选。此入口仍以待复核区间为起点，不提供任意位置拖选。

每条记录保留原始文件、文件内序号、qN、哈希与全部候选命中。匹配所选关系的命中默认展开并明确标注；其他候选保留为折叠项。区间内配对/删除的裁剪坐标分别取该记录所有候选的并集，两者可能重叠，不据此建立共识。候选命中数不会增加返回的记录数，withheld-only 记录没有可推断的位置。

读取接口：`GET /api/revisions/{revision_id}/alignments/{job_id}/reads?start=200&end=207&relation=either&limit=3&offset=0`。

- start/end 必须同时指定，满足 0 ≤ start < end ≤ 参考长度；环形跨起点按两段分别查询。relation 为 either（默认）、paired、deletion，无区间时不能指定后两者。
- 精确半开重叠：候选起点 < 查询终点，候选终点 > 查询起点。仅触及边界不算重叠；D 仅产生删除关系，I 不产生参考位置配对。
- 几何复核全部候选后，先按记录筛选、再分页。保留原始查询/来源索引，total 是匹配记录数；unfiltered_total 是原结果记录数；region 返回已应用的区间/关系，无筛选为 null。
- 有筛选时每项增加 region_evidence，包含 paired_intervals、deletion_intervals、matching_hit_indices（0 基候选索引）和 placement_category。区间数组是所有候选裁剪并集，matching_hit_indices 仅列与所选关系重叠的候选。单报告命中类别不证明唯一性。
- 参数非法返回 422；任一候选几何损坏返回 409，即使该候选不在查询区间。未成功发布/来源损坏/跨修订的边界沿用既有 API。

失败时同时保留上次成功的筛选标签与证据，避免新标签配旧结果；关闭或切换构建后迟到的筛选响应不显示。空结果仅说明没有可用的已报告匹配，不证明生物学证据不存在。每次仍扫描全部有界候选，没有新增大规模性能承诺。

新增 10 项区间专项用例覆盖半开相邻、反向/跨起点删除、候选配对与删除交叠、重复候选去重、withheld、坏参数/几何，以及真实 minimap2 后的筛选分页、原记录身份和修订隔离。
