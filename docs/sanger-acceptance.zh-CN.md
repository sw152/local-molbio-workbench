# Sanger 阶段 2 验收范围

2026-10-07：单机个人版的 Sanger 审阅闭环通过当前范围的综合验收，可以推进批量任务基础设施。该结论不是全质粒正确性判定，也不是所有仪器格式的兼容性认证。

| 检查 | 证据 | 结果及边界 |
|---|---|---|
| 真实格式上传与峰图 | Biopython 1.88 的公开 3100.ab1，795 bases；实际上传、峰图翻页与原始坐标跳转 | 通过；未用该文件自身的碱基构造参考并宣称比对准确，也没有它的配套参考 |
| 正反向、未知方向、环状起点和局部匹配 | 有明确预期结果的合成序列及真实二进制合成 ABIF | 回归通过；等分定位和截断保持待审阅 |
| 质量与 indel | Q19/Q20、缺质量、N、缺失内部低质量、跨起点、重复和不同插入事件 | Q20 配对及精确事件对参考的比较通过；重复区归一化、不同 indel 等位事件之间的比较未实现 |
| 参考修订隔离 | 相同序列内容的两个 revision 使用同一 ABIF 内容，各自分析 | 上传、run、摘要和导出隔离；跨 read 的报告 ID 返回 404，跨 run 的重分析前置条件返回 409；原快照保持不变 |
| 混合旧数据 | 同一 revision 同时包含 v4、无映射的 v3 和未分析读段 | 只有 v4 的 170 个 Q20 碱基计入质量覆盖，所有来源及未评估状态随 JSON/HTML 导出 |
| 历史与错误路径 | 历史 run、过期快照、源文件缺失/变更、失败请求、关闭后的迟到响应 | 回归通过；保存的证据导出不重新核验原 AB1，重新分析及峰图访问仍核验原文件 |
| UI 和报告 | M2 Chrome，桌面、390 px、离线 HTML | 截图人工复核：四通道共用幅度尺度、原始位置与质量可见；移动端来源、计数和峰图链接可审阅 |

本轮全部 224 项 Python 测试、11 项 Node 测试通过。Python 存在现有的 Starlette/httpx 弃用警告及重复 ZIP 成员测试警告，无失败。公开样本 SHA-256 为 `78588d824dd967a1e58a9667a8f7ca1687ba38266420bbc5a6562c1893888efd`，执行前与既有来源记录核对一致。来源为 [Biopython 1.88 测试文件](https://github.com/biopython/biopython/blob/biopython-188/Tests/Abi/3100.ab1)。

测试修订由隔离测试数据库直接创建；这不表示已实现用户编辑并创建 revision 的界面。未进行私有研究数据验收、仪器多型号验证、混峰判读或生物学真值验证。本次公开 AB1 仅作为未分析读段加入界面，证明它不会贡献参考支持；最终合成插入事件显示 1 条事件支持、2 条参考支持、2 条未评估。

复现：在项目环境执行 `python -m pytest -q`、`node --test tests/ui/*.cjs`，然后设置 `MOLBIO_PUBLIC_AB1` 为自行准备的公开样本绝对路径，执行 `python scripts/verify_sanger_ui.py`。不设置该变量时只运行合成数据 UI 流程，日志会明确 `public_ab1_checked: false`。公开样本不随包分发，不联网下载依赖样本；截图、隔离数据库和报告仅留在忽略的 `var/` 中。

下一项可验收交付是可恢复的本地批量任务骨架：独立任务输入清单、幂等提交、原子领取、租约与中断恢复、重试保留历史。先验证状态转换和恢复，再接入具体长短读分析器。该骨架本身不产生共识或全质粒通过判定；多用户账户、PostgreSQL、测序适配器仍属后续阶段。
